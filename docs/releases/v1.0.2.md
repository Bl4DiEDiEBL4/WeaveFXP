## WeaveFXP v1.0.2

- Faster mesh scheduling with a shared race scoreboard, fair slot sharing and improved source failover.
- Fixed in-progress X-DUPE handling, duplicate transfers and false SFV/race completion.
- Local transfer queues enforce site limits, cancel on disconnect and support Move up/down and Remove all.
- Live SFV folder banners and faster verification with CRC32 calculated during downloads.
- Site Search in the UI and API with native SITE SEARCH, optional recursive scanning and result queueing.
- Favorites preserve pane positions; added local ALL slots, resume and same-size skipping.
- Added panel Save buttons, startup browser setting and persistent color palettes; improved UI and tray responsiveness.
- Added proxy support, cbftp JSON import and slftp encrypted UDP compatibility.
